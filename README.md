# Pokédex TypeScript

A sleek Pokémon browsing app built with React, TypeScript, and Vite. Search Pokémon by name, filter by type, and explore details in a polished modal interface.

## Live Demo

Visit the deployed app here:

https://ts-pokedex-beta.vercel.app/

## Features

- Search Pokémon by name
- Filter by Pokémon type
- Infinite scrolling load more results
- Responsive card-based layout
- Detailed Pokémon modal with information and navigation
- Modern UI built with React + Tailwind CSS

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The app will start in development mode, typically at:

```bash
http://localhost:5173
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
